# 考研管家 · 鸿蒙安装包

HarmonyOS / 华为 / 荣耀 设备用户，按以下任一方式安装「考研管家」。

## 方式一：浏览器添加到桌面（推荐，最简单）

适用于 HarmonyOS 4.0 及以上。

1. 用 **华为浏览器** 打开本目录下的 `启动.html`
2. 点击页面上的 **「🚀 立即打开考研管家」** 进入 App
3. 浏览器菜单 → **「添加到桌面」** / **「收藏到桌面」**
4. 回到桌面即可看到 📚 考研管家 图标

## 方式二：开发者快应用 / 元服务打包

如需独立的 `.hap` 安装包上架华为应用市场：

1. 下载 [HBuilderX](https://www.dcloud.io/hbuilderx.html)
2. 新建 `5+App` 项目，把 `app/` 目录内容放入项目
3. 菜单 `发行 → 原生 App-云打包`，选择 **HarmonyOS** 通道
4. 实名认证后云端打包，10-20 分钟出 `.hap` 安装包

本项目零依赖、纯前端，可直接打包成功。

## 方式三：HarmonyOS 元服务（原子化服务）

如需"服务卡片"形态（桌面下拉/负一屏），需用 DevEco Studio 创建元服务工程，将本 Web App 通过 `Web` 组件嵌入，再做一张服务卡片即可。

## 特性

- ✅ 离线可用：Service Worker 缓存，首次联网后断网可开
- ✅ 数据本地存储 + 可选 Supabase 云端同步
- ✅ 零原生依赖：纯 HTML/CSS/JS，跨设备一致体验
