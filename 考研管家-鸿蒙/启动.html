📚 考研管家 · 鸿蒙安装

HarmonyOS · 华为/荣耀手机与平板

方式一：浏览器添加到桌面（推荐，最简单）

1
用 华为浏览器（或鸿蒙自带浏览器）打开下方 立即打开 按钮。
2
点击浏览器菜单（右上角 ⋮ 或底部分享）。
3
选择 「添加到桌面」 或 「收藏到桌面」。
4
回到桌面，即可看到 📚 考研管家 图标，点击全屏打开。
HarmonyOS 4.0+ 已支持 PWA / Web App Manifest，会自动获得类原生体验。

方式二：开发者快应用打包（进阶，可上架华为应用市场）

如需分发为独立的 .rpk 鸿蒙原生安装包，可用 HBuilderX 将本 Web App 打包为快应用 / 鸿蒙元服务。

1. 下载 HBuilderX（https://www.dcloud.io/hbuilderx.html）
2. 新建 5+App 项目，将 app/ 目录放入 unpackage/dist/dev/
3. 菜单 发行 → 原生 App-云打包，选 HarmonyOS 通道，提交云端打包
4. 约 10-20 分钟生成 .hap / .app 安装包

云打包需要 DCloud 账号实名；本项目零依赖、纯前端，可直接打包成功。

使用说明

首次打开需联网一次（加载字体 + 缓存资源），之后完全离线可用。所有数据本地存储，关闭重启不丢。

🚀 立即打开考研管家
首次打开后请回到本页面，按上面步骤完成「添加到桌面」。
