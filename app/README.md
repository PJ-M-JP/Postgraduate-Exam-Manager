# 考研管家 · 全周期备考

一个**纯本地、单页、离线可用**的考研备考管理 App，覆盖从择校规划 → 日常学习 → 刷题模考
→ 笔记背诵 → 时间管控 → 报考复试的完整备考周期，共 **6 大模块、49 项细分功能**。

界面采用**手绘便签风**：奶油黄底 + 薄荷绿主色 + 圆胖手写体（ZCOOL KuaiLe 全局统一），
贴纸实色阴影、虚线手绘边框、笔记本装订孔侧边栏，电脑端与本地浏览器均可稳定打开。

---

## 一、如何打开（三种方式）

### 方式 A：本地服务器（推荐，PDF 喂书功能完整可用）
```bash
cd app
python3 -m http.server 8765
# 浏览器访问 http://localhost:8765
```

### 方式 B：直接双击
双击 `app/index.html`，用 Chrome / Edge / 360 极速浏览器打开即可。
> 直接双击（`file://`）下，PDF 解析若被浏览器安全策略限制，可改用「粘贴文本」入口，功能不失效。

### 方式 C：部署到静态托管
把 `app/` 整个目录上传到 GitHub Pages / Vercel / Nginx 静态目录即可，无需后端。

## 二、数据会自动保存吗？
- ✅ 会。所有输入（任务、笔记、错题、复盘…）在改动后 **800ms 自动防抖保存**。
- ✅ 关闭页面、关机后再打开，数据都还在（localStorage + IndexedDB）。
- ✅ 文件/PDF 资料走独立的 **IndexedDB 文件库**，不会撑爆浏览器存储配额。
- 顶部「📤 导出 / 📥 导入」可随时备份/恢复全部数据为 JSON 文件。

## 三、如何开启云端同步（Supabase，多设备共享）
1. 注册 [supabase.com](https://supabase.com) 项目。
2. 后台 **SQL Editor** 执行本目录的 `supabase_schema.sql`（建表 + 行级安全）。
3. 后台 **Settings → API** 复制 Project URL 和 anon public key。
4. 打开 `app/js/config.js`，填入：
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJ..."
   ```
5. 刷新页面，点击左下角状态条 → 用**邮箱+密码登录/注册**。
   - 联网时数据**静默同步**到云端；断网照常用，联网后自动补传。
   - 状态条清晰区分：`离线` / `同步中…` / `已同步·邮箱`。
   - 多设备登录同一账号即可共享全部备考数据。

> 若不填凭据，APP 以纯本地模式运行，左下角显示"离线·数据保存在本地"，功能完全不受影响。

## 六、喂书功能（模块4 核心：PDF → 结构化笔记 + 思维导图）
- 进入「知识笔记 → 📥 喂书生成」，上传 **PDF 课件/教材** 或 **.txt 文本**。
- 纯本地解析（pdf.js，内置于 `vendor/`），**不上传你的文件**。
- 解析后自动：① 生成按章节/要点整理的**结构化笔记**（存入「分科笔记」，可二次编辑）；② 生成**思维导图**（存入「思维导图」库，可反复查看）。
- 扫描版 PDF（无文本层）会自动提示改用「粘贴文本」，粘贴后同样生成笔记+导图。

## 九、首次使用建议
1. 首页设置「考研初试日期」和目标院校信息、各科目标分。
2. 依次填写参考书、网课台账，建立每日任务。
3. 刷题后随手录错题，系统会按艾宾浩斯曲线推送复习。
4. 用「喂书生成」把 PDF 教材转成笔记与思维导图。
5. 每天用番茄钟专注，复盘模块记录当日得失。

## 十、稳定性说明
- 全部依赖本地化：无外部 CDN、无后端，断网可用。
- pdf.js 为本地 `vendor` 文件，离线可用。
- 文件/PDF 走独立 IndexedDB 库，不撑爆浏览器存储配额。
