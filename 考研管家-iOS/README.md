# 考研管家 · iOS 安装包

iPhone / iPad 用户，请按以下步骤将「考研管家」安装到主屏幕，像原生 App 一样使用。

## 安装步骤（约 30 秒）

1. 用 **Safari** 浏览器打开本目录下的 `启动.html`
2. 点击页面上的 **「🚀 立即打开考研管家」** 按钮
3. 页面跳转到 App 后，点击底部分享按钮 ⬆️
4. 在弹出菜单中选择 **「添加到主屏幕」**
5. 名称保持「考研管家」不变，点右上角 **「添加」**
6. 回到主屏幕，即可看到 📚 考研管家 图标

## 特性

- ✅ 离线可用：首次联网一次后，无网也能打开（Service Worker 缓存）
- ✅ 全屏体验：无 Safari 浏览器界面，像原生 App
- ✅ 数据本地存储：localStorage + IndexedDB，关闭重启数据不丢
- ✅ 可选云同步：在 App 内「复盘报考」模块登录 Supabase 账号即可多端同步

## 系统要求

- iOS 11.3 及以上（支持 PWA）
- iPadOS 13 及以上
- 浏览器：Safari（必须用 Safari 添加到主屏幕）
